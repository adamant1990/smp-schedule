# smp-schedule

Отдельное веб-приложение для автоматического составления ежемесячного графика фельдшеров СМП.

## Стек
- Next.js App Router
- TypeScript
- React
- Supabase/PostgreSQL
- ExcelJS
- Vercel

## Принципы
- Основной цикл — «сутки через трое».
- Основные и дополнительные смены разделены.
- Жёсткие ограничения проверяются отдельно от мягкой оптимизации.
- Алгоритм планирования не зависит от UI.
- Закреплённые пользователем смены не изменяются при обычном перерасчёте.
- Проект smp-duty является полностью отдельным и этим репозиторием не изменяется.
